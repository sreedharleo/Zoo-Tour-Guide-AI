# Zoo Tour Guide AI 🐾

## Description
An AI-powered tour guide that helps users explore zoo animals using Gemini AI.

## Problem Statement
Visitors in zoos often lack interactive and engaging guidance about animals.

## Solution
Zoo Tour Guide AI provides real-time, AI-powered explanations using Gemini to enhance user experience.

## Features
- AI-generated animal descriptions
- Interactive responses
- Deployed using Google Cloud Run
  
## How to Use
1. Open the live demo link
2. Ask about any animal
3. Get AI-generated information instantly
